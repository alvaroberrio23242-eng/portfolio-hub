## COMPARACIÓN: NAVEGACIÓN OFICIAL vs ESTRUCTURA DEL PROYECTO

### Navegación oficial (cafelaprotectora.com.ve)

```
INICIO
QUIÉNES SOMOS
ENCUENTRANOS
  ├── RELACIONES COMERCIALES
  └── CENTROS DE DISTRIBUCIÓN AUTORIZADOS
PRODUCTOS
CONTACTO
```

### Rutas construidas en nuestro sub-app Flask (`/cafe/`)

```
/cafe/                    → Index (home conceptual)
/cafe/historia            → Historia de la marca
/cafe/origen              → Origen geográfico (Trujillo)
/cafe/proceso             → Proceso productivo (6 pasos)
/cafe/productos           → Catálogo de productos
/cafe/producto/<slug>     → Detalle de producto individual
/cafe/donde-comprar       → Directorio de distribución
/cafe/cultura             → Cultura del café (contenido editorial)
/cafe/contacto            → Contacto
```

### Análisis de coincidencia/divergencia

| Página oficial | Nuestra ruta equivalente | Coincidencia |
|----------------|--------------------------|--------------|
| INICIO | `/cafe/` | Parcial — home oficial muestra productos y misión; nuestra home es más ambiciosa (hero, timeline, proceso, productos) |
| QUIÉNES SOMOS | `/cafe/historia` + `/cafe/origen` | **Divergencia**: separamos en 2 páginas lo que la marca unifica en 1 |
| ENCUENTRANOS > CENTROS DE DISTRIBUCIÓN | `/cafe/donde-comprar` | Coincidencia funcional |
| ENCUENTRANOS > RELACIONES COMERCIALES | No implementada | **Omisión** — contenido B2B no incluido |
| PRODUCTOS | `/cafe/productos` + `/cafe/producto/<slug>` | **Divergencia**: añadimos páginas individuales por producto (la marca no las tiene) |
| CONTACTO | `/cafe/contacto` | Coincidencia |
| *(no existe)* | `/cafe/proceso` | **Adición nuestra** — la marca muestra el proceso en QUIÉNES SOMOS, no como página separada |
| *(no existe)* | `/cafe/cultura` | **Adición nuestra** — contenido editorial no existe en sitio oficial |

**Conclusión**: Nuestra estructura conceptual es más granular que la oficial. Esto es una decisión de diseño válida para un caso de estudio de UX, pero debe quedar documentado que **no replicamos la estructura del sitio oficial**.
