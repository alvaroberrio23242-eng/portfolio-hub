🎵 SalsaQuest

Experiencia interactiva de cultura salsera

Contexto

Un bar de salsa y son cubano en Medellín necesitaba diferenciarse de la competencia.

Problema

Ningún negocio de salsa en la ciudad ofrecía una experiencia digital interactiva para turistas.

Solución

Aplicación web con storytelling gamificado, trivia interactiva, biografías de artistas, línea de tiempo y leaderboard.

  • Línea de tiempo interactiva de la historia de la salsa, filtrable por década
  • Biografías de artistas con modal de detalle
  • Trivia salsera gamificada con reto diario, puntos y leaderboard
  • Registro de usuarios con captura de datos
  • Reproductor de Spotify embebido con playlist oficial

LAP Video

Estudio local de edicion y compresion de video con FFmpeg

Codigo ↗

Aplicacion web local para editar y comprimir video. Se sube un archivo, se ajustan recorte, velocidad, color y exportacion con una vista previa en vivo, y un procesador FFmpeg en segundo plano genera el MP4 final con progreso en tiempo real.

  • Recorta, cambia la velocidad y aplica brillo, contraste, saturacion, desenfoque y escala de grises con vista previa en vivo
  • Exporta ajustando resolucion, FPS, calidad (CRF) y preset, o comprimiendo a un tamano objetivo en MB
  • Procesa en cola con barra de progreso y opcion de cancelar, sin bloquear la interfaz
  • Interfaz con carga por arrastrar y soltar, fondo de video y diseno translucido
  • Cubierta por 45 pruebas automaticas del backend Flask y del motor de video

Benja Karaoke

Karaoke web con modo escenario, letras sincronizadas y API Flask

Demo ↗Código ↗

Aplicación web de karaoke que combina reproducción de audio local, letras con marcas de tiempo y una interfaz inmersiva con modo escenario. Incorpora controles de reproducción y navegación temporal, volumen, atajos de teclado y consulta del estado de una API Flask desplegada en Render. La reproducción local sigue disponible aunque la API no responda.

  • Reproducción de archivos de audio locales directamente en el navegador
  • Carga manual de letras con marcas de tiempo en formato segundos|texto
  • Visualización de la frase actual y referencias de las frases anterior y siguiente
  • Ajuste temporal de las letras durante la reproducción
  • Controles de progreso, tiempo transcurrido y duración, volumen y silencio
  • Navegación temporal configurable y controles para reiniciar la reproducción
  • Modo escenario y atajos de teclado para facilitar el uso durante el karaoke
  • Consulta del estado de la API Flask con mensajes accesibles y alternativa local si no está disponible
  • Búsqueda externa de canciones en YouTube

EduPack Builder

Constructor de paquetes educativos con recursos de licencia libre

Ver demo ↗Código ↗

Aplicación web que arma un paquete educativo en .zip a partir de un tema. El usuario escribe la guía docente y la trivia, y la app consulta cinco APIs públicas —Wikimedia Commons, Openverse, Internet Archive, GitHub y Wikipedia—, filtra por licencia libre y reúne imágenes, enlaces de video, repositorios y artículos.

  • Consulta cinco APIs públicas —Wikimedia Commons, Openverse, Internet Archive, GitHub y Wikipedia— sin claves de API
  • Filtra imágenes por licencia (CC BY, CC BY-SA, CC0, dominio público) antes de incluirlas
  • Descarga las imágenes como archivos reales del paquete y reúne videos y repositorios como enlaces con su licencia y fuente
  • Compila una bibliografía con fuente, autor, licencia y enlace de cada recurso incluido
  • Empaqueta la guía docente, la trivia, las imágenes y los listados de fuentes en un .zip descargable
